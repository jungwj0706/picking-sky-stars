# 밤하늘 예보 데이터 형식

웹은 `public/data/index.json`으로 제공되는 JSON 한 파일을 읽는다. 모델 연동 시에도 해당 경로에 같은 형식의 한 날짜 분량을 게시하면 된다.

## 예보 시간

- 기준 시간대는 한국 시간(`Asia/Seoul`)이다.
- 당일 오전 6시까지의 관측 자료로 그날 22시부터 다음 날 02시까지를 예측한다.
- 다섯 시각의 하늘 상태를 종합해 서울 공통 하늘 상태 점수를 만든다. 지도에 표시하는 값은 각 격자의 밤 전체 점수다.

## 필드

- `kind`는 화면 시연용이면 `sample`, 해당 날짜의 예측 결과면 `forecast`다.
- `nightDate`는 밤이 시작하는 날짜를 `YYYY-MM-DD` 형식으로 지정한다. `sample`에는 `null`을 사용한다. `forecast`의 날짜는 한국 시간 기준 조회일과 일치해야 한다.
- `gridSizeMeters`는 정사각형 격자 한 변의 길이다. 정수나 실수를 쓸 수 있고 단위는 미터다. 모델 격자는 250m다.
- `nightSkyScore`는 그날 밤에 서울 전체에 적용되는 하늘 상태 점수다. 범위는 0~1이다.
- `meanCloudCover`는 다섯 시각의 예상 전운량 평균이다. 범위는 0~10이고 제공할 수 있을 때만 포함한다.
- `cells`는 서울 경계 안에 포함되는 격자 배열이다.
  - `id`는 파일 안에서 중복되지 않는 격자 ID다.
  - `center`는 WGS84 십진수 좌표이며 `[경도, 위도]` 순서다.
  - `placeScore`는 격자의 관측 조건 점수다. 범위는 0~1이다.
  - `score`는 격자의 최종 밤 전체 점수다. 현재 모델은 `placeScore × nightSkyScore`로 계산하며 범위는 0~1이다.

웹은 점수에 100을 곱하고 반올림한다. 시연용 등급은 표시 점수를 기준으로 0~39점은 ‘나쁨’, 40~69점은 ‘보통’, 70~100점은 ‘매우 좋음’으로 구분한다. 실제 결과를 받을 때 점수 분포를 보고 등급 구간을 팀에서 검토할 수 있다.

## 샘플 응답

```json
{
  "kind": "sample",
  "nightDate": null,
  "gridSizeMeters": 460,
  "nightSkyScore": 0.92,
  "meanCloudCover": 2.4,
  "cells": [
    {
      "id": "sample-42-34",
      "center": [126.979, 37.56],
      "placeScore": 0.565,
      "score": 0.5198
    }
  ]
}
```

## 예보 없음과 오류

- HTTP 204 또는 404, 빈 `cells` 배열, 조회일과 다른 `nightDate`의 실제 결과는 오늘 밤 예보가 없는 상태로 표시한다.
- 네트워크 오류, 다른 HTTP 오류, 잘못된 JSON은 실패로 표시하고 다시 시도할 수 있다.
- 예보 갱신 요청이 실패하면 마지막으로 성공한 예보를 화면에 유지하고 안내를 표시한다.
